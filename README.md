## La Biblia del Parrillero Peruano

Ebook de Carnes Delivery Premium (Dennis Castro), incluido en este repositorio:

- `biblia-del-parrillero-peruano.html` — fuente editable (diseño premium, para ver en navegador o re-exportar).
- `biblia-del-parrillero-peruano.pdf` — versión exportada para imprimir/compartir.
- `biblia-del-parrillero-peruano.epub` — versión exportada para Apple Books y otros lectores EPUB.

Para regenerar el PDF o el EPUB tras editar el `.html`, ver los comandos usados en el historial de commits de este archivo (Chromium headless `--print-to-pdf` y `pandoc ... -t epub3`).
